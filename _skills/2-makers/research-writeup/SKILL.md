# 研究级总结（跨学科）

## 这个 skill 解决什么

用户要的是能信、能追问的总结：读完知道这件事想干什么、为什么可以这么做、为什么要这么做、得到了什么；每条命题知道它站得多稳；引用都查过；第一版先把主线讲清楚，细节靠追问长出来。这个 skill 把这套做法固定下来，并对不同学科分别说明"严格"在那里是什么意思。

## 开始前

1. 判断学科，读下面对应的模块：数学 / 理论物理 → 模块 A；统计 / ML / 计算机 → 模块 B；哲学 → 模块 C；其他 → 模块 D。跨学科题目读两个模块，并做双列术语表。
2. 定读者档位：数学物理默认博士生，其他学科默认本科生。用户说了别的以用户为准。
3. 快变领域（ML、生物医学、任何"现在怎么看"的问题）先搜后写，标注检索日期。
4. 回复开头用一行报默认规格并问核验要求，不等回答就开始写：「按博士生档、四问纲领、核验 10 条引用写；要改告诉我。」由 flow-research 调用时，规格由它报，这里不重复。

## 全文纲领：四问

四问——**想干什么 / 为什么可以这么做 / 为什么要这么做 / 这么做有什么结果**——组织整篇文档。它是全文的纲领，不是每节、每个定理都要答一遍的模板。

- **一页摘要**就是对整个题目回答这四问，各一小段。
- **主线**大体按四问的顺序展开：问题与动机（想干什么）→ 关键想法为什么行得通（为什么可以）→ 为什么走这条路而不是别的（为什么要）→ 结论、例子与影响（有什么结果）。
- **节内**按内容需要写：定义、精确陈述、论证、直觉、图。一节和四问里的哪一问相关，用一句话交代即可。
- 检查标准：只读摘要的人能复述这四问的答案；读完主线的人能说出关键一步为什么成立。

## 分层交付：第一版只写主线

第一版 = 一页摘要 + 主线。主线把每个核心结论讲到"知道它说什么、为什么对、站得多稳"，不穷尽细节。原因：用户会追问，追问比一次写全更准，也更省读的时间。

- 标准技术步骤过长时省略，写一句「标准，略」并点名技术名称；核心论证不省。
- 结尾列「可追问的方向」：五条以内，每条一句话说展开后能得到什么。
- 追问的回答在对话里给；超过一屏或自成一节的，写进文档附录并重出 PDF。文档只有一份，带日期与版本号，随追问生长；新命题追加进命题台账。

## 五条跨学科合同

1. **可信度标注，每条命题都有。** 通用词汇是四级：已确立（引文 + 证据等级）/ 有争议 / 单一来源 / 推测。四级是词汇表，不是模板：每个模块按本学科内容定义自己的标签，写清楚和四级的对应关系；对不上的就写对不上。为了匹配而匹配会把"物理论证"硬塞成"单一来源"，读者反而误解。
2. **固定骨架：** 这个领域在解决什么问题 → 核心对象与定义 → 主要结论的精确陈述 → 论证或证据（核心论证保留，并解释直觉为什么对）→ 直觉与图 → 缺失清单与下一步 → 引用（全部核验过）→ 附录：命题台账、引用台账。篇幅短时合并节，不省项。
3. **最小可校验的例子：** 每个模块定义本领域"最简单的非平凡情形"是什么，文中给出它。实际计算（符号计算、重算统计量、跑复现）只在用户要求时做；没做就写「未算」，不让读者以为验过了。
4. **交付：** Markdown + PDF，PDF 用 flavored-notes 的构建脚本（见下文"PDF 构建"）。三层：一页摘要 / 主线 / 附录。用户对格式有反馈时以反馈为准，数据密集的可换 notebook。
5. **诚实条款：** 缺失清单必须有，写明「这里我不知道」「这里文献里没有」；引用核不到就标「未核实」；分歧写分歧，不替学界下结论。

## 引用核验

按 citation-check 执行：用 Skill 工具加载它，它是引用规则的唯一来源（什么算核实、预算怎么用、台账格式、各领域到哪里核）。本 skill 的默认预算是 10 条，用户可改；引用台账放进附录。

## 命题台账（附录）

每条进入主线的命题一行；追问新增的命题追加在后面，不改旧编号。标签用所在模块的标签。

| 编号 | 命题（一句） | 标签 | 来源 | 核实方式 | 核实日期 |
|---|---|---|---|---|---|

## 独立审稿

主线超过一屏，或用户说这份很重要时必做。

- 成稿构建好之后，派一个新的子 agent，只给它构建出的 Markdown 和下面的攻击清单，不给写作过程、来源笔记或你的推理；它可以自己打开文中引用的来源。
- 让它逐条回报：位置、问题、为什么、能否修。
- 攻击清单（按模块）：
  - **A**：漏掉的假设或量词顺序；把物理论证写成"已证"；张冠李戴的归属；边界情形（低维、非紧、特征 2、非单连通）；记号前后不一。
  - **B**：数据泄漏或基准污染；把预印本当同行评审；只有点估计、没有方差或重复次数；把相关写成因果。
  - **C**：偷换概念；前提里藏着结论；稻草人；把少数立场写成共识。
  - **D**：识别策略的漏洞；效应量或置信区间缺失；撤稿或已被推翻的研究；只引一方。
- 修完再交付。交付说明里写：审稿发现 N 条，已修 M 条，其余的说明原因（接受风险，或需要用户决定）。
- 没有子 agent 时开新会话代审；都做不到，就标「未经独立审稿」。

## PDF 构建

- 用 flavored-notes 的构建脚本：找到 `flavored-notes/scripts/build_note.py`（例如 `find / -path '*flavored-notes/scripts/build_note.py' 2>/dev/null | head -1`），源文件按 flavored-notes 的 "Source format" 一节写（编号的定理与公式、交叉引用、中文用 `lang: zh`）。
- 脚本会报页数、编译错误、未解析的引用、溢出行和缺字，并把每页渲染成预览图：看预览图，不只看日志。
- 图：交换图用 `\begin{CD}`；其余几何图用 TikZ（写在 `{=latex}` 块里，只进 PDF，Markdown 里附一句说明）；数据图和示意图存成 PNG，用相对路径插入。有图片时，在源文件所在目录运行脚本，命令前加 `TEXINPUTS="$PWD//:"`：脚本在临时目录里编译，不加的话找不到图片。
- 找不到脚本时退回 pandoc + xelatex（中文用 CJK 字体）；PDF 失败就交 Markdown 并说明。

## 交付前清单

逐项打勾，写在交付说明里：

- [ ] 摘要回答了四问
- [ ] 每条命题都有标签
- [ ] 核验数 / 预算（未核实的已标注）
- [ ] 缺失清单写了（是空的就说明为什么）
- [ ] 每张图下有一句读法
- [ ] 版本号与日期

## 数学类比

只有当数学结构确实是该学科结论的本质时才引入（网络的谱、博弈的均衡、统计的信息几何）。"可以这样类比"不是引入的理由。原因：用户明确不要把话题往数学上带。

## 图

- 几何直觉图、机制图、流程图、论证树按模块选；每张图下一句话说读法。
- 数据图只画真实数据并写来源；没有真实数据就画示意图并标「示意」。
- 画不出的用文字描述几何图像。

## 争议与价值判断

有政策或政治敏感性的题目（经济、社科、医学政策）多方立场并列，各方的最强论据都给，不下结论。哲学用「前提—推论—反驳」的论证重构代替证明。

## 术语

跨学科时给双列术语表：同一个词在两个领域各指什么（model、field、symmetry、regularization、identification 都是重灾区）。本科生档定义每个术语；博士生档只定义非标准的。

## 模块 A：数学 / 理论物理（默认博士生档）

**精确陈述长什么样**：定义 → 定理或猜想（带全部假设、归属、年份）；物理结论写成模型 + 作用量或哈密顿量 + 结论。数学和物理两种语言并列，给对偶字典表。

**标签**：已证（引文）/ 物理论证（物理里成立，数学未证）/ 猜想（谁提出、哪年）/ 我的推测。对应四级：已证 → 已确立；猜想 → 单一来源；推测 → 推测；**物理论证对不上四级里的任何一级**，保留原标签，并注明数学那边的状态。

**论证的写法**：核心论证保留——证明的结构、关键引理、为什么这条路走得通；标准技术步骤（谱序列计算、紧性论证、正则性估计这类）过长时省略并点名；每个定理后一段"为什么对"的直觉。

**最小校验例子**：最简单的非平凡情形——阿贝尔情形、秩一、低维、自由理论、有限群，视对象而定；并做一致性检查：极限情形、对偶两边是否吻合、量纲或标度。符号计算只在要求时做。

**图**：几何直觉图（纤维化、模空间、Weyl 房、流）、交换图、对偶字典表。

**引用**：按 citation-check（数学、理论物理一栏）。

**读者档位**：博士生——不解释标准概念（概形、栈、TQFT 公理、路径积分），定义一切非标准的；在用户熟悉的领域沿用该领域的标准记号。

## 模块 B：统计 / ML / 计算机（默认本科生档）

**精确陈述长什么样**：问题设定（数据的假设、目标）→ 方法（估计量、模型或算法，给伪代码）→ 结论：定理（有限样本或渐近，列全假设）或经验结果（数据集、指标、效应量、置信区间或重复次数、算力）。

**标签**：定理（有证明）/ 多数据集独立复现 / 单论文单基准 / 轶事或猜测。对应四级：定理与多数据集复现 → 已确立；结果互相矛盾 → 有争议；单论文 → 单一来源；轶事 → 推测。预印本单独标明。

**最小校验例子**：玩具情形的推导（线性、一维、高斯、两类）或小规模复现；复现只在要求时做，否则标「未复现」。数量级检查：参数量、数据量、算力是否自洽。

**图**：模型结构图；机制示意（偏差—方差、训练曲线）标「示意」；真实曲线只用真实数据并给来源。

**引用**：按 citation-check（统计、ML、计算机一栏）；领域按月变，检索日期必写。

**术语**：统计与 ML 名称对照（系数 / 权重、正则化 / 先验、协变量 / 特征、泛化误差 / 测试误差）。

**读者档位**：本科生——定义所有术语，直觉先于公式。

## 模块 C：哲学（默认本科生档）

**精确陈述长什么样**：论证重构——编号前提 → 推论 → 结论；标明论证类型（演绎、归纳、最佳解释推理、思想实验）；关键概念给出定义，有竞争定义的并列。

**标签**：广泛接受的区分或结果 / 主流立场但有争议 / 少数立场 / 我的重构或推测。对应四级：广泛接受 → 已确立；主流有争议 → 有争议；少数 → 单一来源；推测 → 推测。哲学没有「已证」，不要造一个。

**最小校验例子**：一个反例或一个思想实验案例，逐条测试前提；有效性（形式上是否推得出）和前提可信度分开评。

**图**：论证树、立场地图（立场与反驳的连线）、概念区分表；没有数据图。

**引用**：按 citation-check（哲学一栏）。

**术语**：同一词在不同传统里的含义（realism、idealism、intuition）；中英译名对照。

**读者档位**：本科生；立场多方并列，不下结论。

## 模块 D：其他学科兜底（经济社科、生物医学、化学、工程…；默认本科生档）

**精确陈述长什么样**：主张 = 对象 + 量 + 条件 + 方向与大小（效应量）。经济社科补识别策略（因果从哪来：实验、工具变量、断点、双重差分）；实验科学补设计（样本量、对照、盲法、预注册）；系统类补设置（硬件、基准、版本）。

**标签（按每个结论定，不按研究类型）**：同一结论有多项独立研究或元分析支持、方向一致且偏倚风险低 → 已确立；结果互相矛盾 → 有争议；只有单项研究或预印本 → 单一来源；无研究 → 推测。每个结论同时写效应量（带置信区间）和偏倚风险（低 / 有顾虑 / 高，并说依据）。低质量的元分析不能只凭"元分析"三个字升为已确立。生物医学另查是否撤稿。

**最小校验例子**：量纲、数量级、内部一致性（表里的数加起来对不对，效应方向与机制是否相符）；重算只在数据可得且用户要求时做。

**图**：机制图（因果链）、流程图；数据图只用真实数据，否则示意并标明。

**引用**：按 citation-check（生物医学、经济社科两栏）。

**术语**：首次出现即定义。

**读者档位**：本科生。

## 不要做的

- 第一版就穷尽细节。
- 把四问写成每一节的固定小标题。
- 没核实的引用不加标注就放进去。
- 用"看起来像定理"的句子写推测。
- 把四级标签硬套在对不上的内容上。
- 没要求就跑计算或复现。
