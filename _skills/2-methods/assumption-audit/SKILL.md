# assumption-audit：检验假设，产出新知

来源：Felix Rieseberg《How to be more ambitious》中「深度」部分的「挑战已知」和「产出新知」。很多被当作事实的结论只是粗略的近似；把原始材料交给 Claude，让它站在对立面去检验，再顺势找出盲点。

## 何时用

- 有一个默认结论（例如「流失主要是新手引导的问题」「这个策略赚钱是因为动量」「这篇论文的结论成立」），而且有原始数据或一手材料可以查。
- 用户说「帮我验证一下」「这个说法靠得住吗」「从数据里看看是不是这样」。

不用：没有任何原始材料、只能凭常识判断的问题，直接讨论即可。

## 与其他 skill 的关系

- **在 deeper-not-bigger 之后**：标准和外部裁判先定，再检验具体结论。
- **让给**：要的是一个领域或一篇论文的总结 → research-writeup；没有原始材料 → 直接讨论。
- **一轮只停一次**：单独使用时只在第 2 步停一次（选方案）；用户说了“按推荐做”或不在场时，按推荐方案直接往下做。不自行串接其他方法。
- **由 flow 编排时**：第 2 步的方案选择并进它的批示单，不单独停。
- **小任务**：结论能用一个查得到的数直接回答（「上个月退款率超过 5% 了吗」）时，直接查、直接答。

## 流程

### 第 1 步：把信念写成可检验的命题

- 写出三件事：命题本身；如果它成立，数据里应该出现什么；出现什么就算被推翻。
- 有歧义的词（「主要原因」「有效」「显著」）先给出可以操作的定义。
- **写明信念从哪来、已经看过哪些数据**：谁、根据什么得出的；用户和你已经看过哪一部分数据。信念如果是从同一批数据里看出来的，在这批数据上「复现」它只是循环论证——写明这一点，把检验放到没看过的那部分上。

### 第 2 步：盘点材料，给出方案让用户选（开工前）

- 列出手上的材料：数据的格式、规模和时间范围；文献或文本；还缺什么。
- 根据材料给出 2 到 3 种做法，每种写明：要做什么、输出什么形式、大致工作量、能回答到什么程度。输出形式按数据而定，例如：
    - 一份分析报告（文档；数值多时加图表）；
    - 一个用户可以在本地运行的小程序或模拟（附运行说明），让用户自己调参数、复现结论；
    - 当前环境跑不了代码时，一段可以直接粘贴进 Claude Code 的实现提示。
- 每种做法都写清两件事：
    - **留出怎么切**：有时间维度就按时间切，最近一段封存；没有就随机留出 20%–30%，固定随机种子。
    - **分析计划**：要算的量、排除规则、多重比较怎么处理，以及规格网格——一个称职的分析者可能做出的不同选择（指标口径、样本过滤、控制变量、时间窗、函数形式），全部列出。
- 等用户选定后再开工。选定之后、看任何结果之前，先把留出集切好封存。

### 第 3 步：对抗性复现

- 目标是尽力推翻这个命题，而不是证明它。只用非留出的部分。
- **推翻交给隔离的对手**：派一个子 agent，只给它命题、推翻判据、原始数据（不含留出部分）和分析计划，不给支持方的推理和你的初步看法，让它尽力推翻；它可以跳出分析计划去找漏洞，跳出的地方单独报告。没有子 agent，就交一段能直接粘贴进新会话的提示（只含命题、判据、数据位置和分析计划）；都做不到，就自己做，并标「未经隔离检验」。
- 数据证据：直接从原始数据计算，不用别人已经汇总好的数字；逐一检查替代解释，包括混杂因素、选择偏差、时间趋势和样本构成的变化。按分析计划跑完整个规格网格，报告结论在多大比例的规格下成立、方向是否一致，不只报一个规格。偏离计划的地方记下理由。
- 文本或文献证据：检验论证能否从原始材料复现——原始数据或推导是否支持结论、引用是否真的说了这件事、关键一步有没有被跳过。

### 第 4 步：给出结论

- 三选一：支持、反驳或无法判断，每种都附证据和置信程度。
- 「无法判断」时，说清楚还缺什么材料才能判断。

### 第 5 步：找盲点，产出新知

- 只在非留出部分上找：在已经读透的材料里，找出还没被注意到的信号或更早的先兆，例如比现有指标更早出现的流失信号。
- 需要时，建一个能复现历史情况的简单模型或模拟，用它来找信号。

### 第 6 步：样本外验证

- 用封存的留出集检验第 5 步的发现能否预测。留出集只用一次：一旦用它做过选择，就不再算样本外，要写明。
- 没有留出数据时照常交付，但在结论上明确标注「未经样本外验证」，并说明需要什么数据才能验证。

## 没人在场时

按推荐的方案开工（只做可逆的分析），开头写明选了哪个方案、为什么；留出集照样先封存。

## 交付内容

1. 命题、可检验的定义、信念来源和已看过的数据。
2. 结论（支持、反驳或无法判断）及证据，包括规格网格的结果和对手的推翻尝试。
3. 新发现的信号及其验证结果，或「未经样本外验证」的标注。
4. 用户在第 2 步选定形式的产物：报告、本地程序或 Claude Code 提示。

## 常见失败

- 用汇总数字代替原始数据。
- 只找支持证据。
- 把相关当成因果，不检查替代解释。
- 先看了全部数据，再切留出集。
- 只报最好看的那一个规格。
- 在同一批数据上既找信号又验证信号。
