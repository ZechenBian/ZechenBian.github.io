**What is it trying to do?** Build networks for images, and other data on a grid, that use the structure of the domain: nearby pixels are related, and the same object can appear anywhere.
**Why can it be done this way?** Translation symmetry pins down the linear layer. The linear maps that commute with all shifts are exactly the convolutions (section 2), so asking for equivariance gives up nothing within that class, and a filter has a handful of weights however large the image (section 3). Pooling over positions then turns equivariance into invariance.
**Why should it be done this way?** The bias matches the data: image statistics are roughly the same everywhere, so a detector learned in one place should work in another, without examples at every position (first experiment). Depth gives large receptive fields and features built from features, and residual connections make depth trainable (section 5).
**What comes out?** On ImageNet, top-5 error fell from 26% before AlexNet to under 4% with ResNet four years later (section 4). Two experiments: a convolution generalizes to positions it never saw while a dense network does not; deep plain networks train worse than shallow ones, deep residual networks do not.
:::

## 1. Inductive bias: locality, equivariance, invariance

An *inductive bias* is an assumption built into a model before it sees data: it restricts or ranks the functions the model can learn. Every model has one; the question is whether it matches the data.

:::thm Definition | Translations, equivariance, invariance
Let a signal be a function $x\colon G \to \mathbb{R}^C$ on a grid $G$, for images $G = \mathbb{Z}^2$ or the torus $\mathbb{Z}_N^2$, with $C$ channels. For $v \in G$ the translation is $(T_v x)(p) = x(p - v)$. A map $f$ from signals to signals is *translation equivariant* if $f(T_v x) = T_v f(x)$ for all $v$ and $x$, and a map $g$ from signals to vectors is *translation invariant* if $g(T_v x) = g(x)$. A map is *local* with radius $r$ if $f(x)(p)$ depends only on $x$ restricted to the ball of radius $r$ around $p$.
:::

The figure at the top shows a convolution behaving equivariantly and a dense layer not. Classification needs invariance (a cat moved ten pixels is still a cat), but the layers before the decision need equivariance: they should report where a feature is, so that later layers can combine features by their relative positions.

:::thm Proposition | Building invariant networks from equivariant layers
1. Compositions of equivariant maps are equivariant.
2. A pointwise nonlinearity, $f(x)(p) = \sigma(x(p))$, is equivariant.
3. If $f$ is equivariant on signals over a finite group $G$, then $g(x) = \frac{1}{\lvert G\rvert}\sum_{p} f(x)(p)$ and $g(x) = \max_p f(x)(p)$ (channelwise) are invariant.
:::proof Proof
(1) $f_2(f_1(T_v x)) = f_2(T_v f_1(x)) = T_v f_2(f_1(x))$. (2) $\sigma((T_v x)(p)) = \sigma(x(p - v))$. (3) $f(T_v x) = T_v f(x)$, and a sum or maximum over all $p$ of $f(x)(p - v)$ is the same as over all $p$ of $f(x)(p)$, since $p \mapsto p - v$ is a bijection of $G$.
:::

:::thm Heuristic | Why these biases fit images
The statistics of natural images are roughly stationary: the distribution of a small patch hardly depends on where in the image it is taken. Correlations between pixels decay with distance, so most of the information about a pixel's meaning is nearby, and objects are built hierarchically from parts. Locality and weight sharing encode the first two; depth encodes the third.
:::

## 2. Convolution is forced by translation symmetry

Work on the cycle $G = \mathbb{Z}_N$ (or the torus $\mathbb{Z}_N^2$), so that every shift is a bijection and there are no borders.

:::thm Definition | Convolution
For $k, x\colon \mathbb{Z}_N \to \mathbb{R}$, $(k * x)(p) = \sum_{q \in \mathbb{Z}_N} k(p - q)\,x(q)$. With channels, $k\colon \mathbb{Z}_N \to \mathbb{R}^{C'\times C}$ and $(k * x)(p) = \sum_q k(p - q)\,x(q) \in \mathbb{R}^{C'}$. (Deep learning libraries compute $\sum_q k(q - p)x(q)$, a cross-correlation, and call it convolution; this only reflects $k$.)
:::

:::thm Theorem | Translation-equivariant linear maps are convolutions
A linear map $L\colon (\mathbb{R}^C)^{\mathbb{Z}_N} \to (\mathbb{R}^{C'})^{\mathbb{Z}_N}$ commutes with every translation $T_v$ if and only if $L x = k * x$ for some $k\colon \mathbb{Z}_N \to \mathbb{R}^{C'\times C}$, and then $k$ is unique. The same holds on $\mathbb{Z}_N^d$ and on any finite abelian group.
:::proof Proof
Convolutions commute with translations: $(k * T_v x)(p) = \sum_q k(p - q)x(q - v) = \sum_{q'} k(p - v - q')x(q') = (T_v(k * x))(p)$. Conversely, let $e_{q,c}$ be the signal that is the $c$-th unit vector at $q$ and 0 elsewhere, and define $k(p)$ as the matrix whose $c$-th column is $(L e_{0,c})(p)$. Since $e_{q,c} = T_q e_{0,c}$ and $L$ commutes with $T_q$, $L e_{q,c} = T_q L e_{0,c}$, whose value at $p$ is the $c$-th column of $k(p - q)$. By linearity, $(Lx)(p) = \sum_{q,c} x_c(q)\,(L e_{q,c})(p) = \sum_q k(p - q)\,x(q)$. Uniqueness: $k$ is read off from $L e_{0,c}$.
:::

So "the most general linear map that commutes with translations" is a convolution with an arbitrary kernel of full size $N$. Locality is a second, independent assumption: a CNN restricts $k$ to a small support, $3\times3$ say. In matrix form, translation equivariance makes the weight matrix circulant, and locality makes it banded.

:::fig circulant | A dense layer from 12 inputs to 12 outputs has 144 independent weights (shades on the left). A translation-equivariant one is circulant, constant along each wrapped diagonal; with locality, only three diagonals are nonzero, and the whole layer has three weights a, b, c (right).

The same structure has a spectral description, the reason convolutions are cheap to compute for large kernels.

:::thm Proposition | The Fourier transform diagonalizes convolutions
Let $\hat x(\omega) = \sum_p x(p)e^{-2\pi i\omega p/N}$. Then $\widehat{k * x}(\omega) = \hat k(\omega)\,\hat x(\omega)$. Equivalently, the characters $p \mapsto e^{2\pi i\omega p/N}$ are common eigenvectors of all translations, and hence of all convolutions.
:::proof Proof
Substitute $p = q + m$:
$$\begin{aligned} \widehat{k * x}(\omega) &= \sum_p \sum_q k(p - q)\,x(q)\,e^{-2\pi i\omega p/N} \\ &= \sum_q x(q)e^{-2\pi i\omega q/N}\sum_m k(m)e^{-2\pi i\omega m/N} \\ &= \hat x(\omega)\,\hat k(\omega). \end{aligned}$$
:::

The theorem generalizes beyond translations. For a group $G$ acting on the domain, linear maps between feature spaces that commute with the action are generalized convolutions over $G$; Kondor and Trivedi (2018) prove this for compact groups, and Cohen and Welling (2016) build networks equivariant to rotations and reflections this way. Spherical CNNs and graph neural networks follow the same recipe with other symmetry groups.

Real networks are only approximately equivariant. Zero padding breaks the symmetry at the border (the figure at the top), and strides and pooling with a step larger than 1 break it in between.

:::thm Empirical | Standard CNNs are not shift invariant (Azulay and Weiss 2019; Zhang 2019)
Shifting an image by a single pixel changes the predicted class of widely used ImageNet networks surprisingly often, because a stride of 2 subsamples the feature map and a one-pixel shift moves features between the kept and the discarded positions. Zhang (2019) restored much of the invariance by blurring before subsampling (anti-aliasing), with a small gain in accuracy.
:::

## 3. The architecture: filters, channels, pooling

:::thm Definition | Convolutional layer
A layer with $C$ input channels, $C'$ output channels, kernel size $k\times k$ (odd, $r = (k-1)/2$), stride $s$ and zero padding computes
$$y_{c'}(p) = b_{c'} + \sum_{c=1}^{C}\sum_{u\in\{-r..r\}^2} K_{c',c}(u)\,x_c(sp + u),$$
with $x$ taken to be 0 outside the image. Each output channel is a *feature map*, each $K_{c',\cdot}$ a *filter*. A *pooling* layer replaces each window, typically $2\times2$ with stride 2, by its maximum or average; *global average pooling* averages each channel over the whole image.
:::

:::thm Proposition | Parameters and receptive fields
1. A $k\times k$ convolution from $C$ to $C'$ channels has $k^2CC' + C'$ parameters, independent of the image size.
2. A stack of $L$ convolutions with kernel sizes $k_1, \dots, k_L$ and strides $s_1, \dots, s_L$ gives each output unit a receptive field of side $1 + \sum_{l=1}^{L}(k_l - 1)\prod_{m<l}s_m$.
:::proof Proof
(1) There is one $k\times k$ kernel per pair of input and output channels, and one bias per output channel. (2) By induction on $L$: one more layer of kernel $k_L$ widens the window of the layer below by $k_L - 1$ of its units, each of which covers $\prod_{m<L}s_m$ input pixels further.
:::

For a $224\times224\times3$ image, a dense layer to an output of the same size has $150{,}528^2 \approx 2.3\times10^{10}$ weights, and even a dense layer to 1,000 class scores has about $1.5\times10^8$. A $3\times3$ convolution from 3 to 64 channels has 1,792 (first check question). Two stacked $3\times3$ layers see a $5\times5$ window with $2\cdot9C^2 = 18C^2$ weights, against $25C^2$ for one $5\times5$ layer, and with a nonlinearity in between; that was the design argument of VGG.

:::fig receptive | Stacking width-3 filters: one unit in layer 4 depends on 9 input positions. The receptive field grows linearly with depth at stride 1, and multiplicatively with strides, which is why networks subsample as they go deeper.

A classification network alternates convolutions and nonlinearities, subsamples by pooling or strides while increasing the number of channels, and ends with global average pooling and a linear layer to the class scores. By the proposition in section 1, everything before the pooling is (up to borders and strides) equivariant and the scores are invariant.

## 4. Case study: ImageNet, from AlexNet to ResNet

The ImageNet Large Scale Visual Recognition Challenge (ILSVRC) asked for one of 1,000 classes for each image, trained on about 1.28 million labelled images; the standard metric is top-5 error, the rate at which the true class is not among a model's five guesses.

:::thm Empirical | ILSVRC results (Russakovsky et al. 2015 and the cited papers)
- 2012, AlexNet (Krizhevsky, Sutskever and Hinton): 5 convolutional and 3 dense layers, about 60 million parameters, ReLUs, dropout, data augmentation, trained on two GPUs. Top-5 error 15.3%, against 26.2% for the next entry, which used hand-designed features.
- 2014, VGG (Simonyan and Zisserman): 16 to 19 layers of $3\times3$ convolutions, 138 million parameters for VGG-16, most of them in the dense layers. Top-5 error 7.3%; GoogLeNet won that year with 6.7%.
- 2015, ResNet (He et al.): residual networks up to 152 layers, with global average pooling instead of large dense layers (ResNet-50 has about 25 million parameters). An ensemble reached 3.57% and won.
- For comparison, one trained human annotator was measured at about 5.1% top-5 error on a sample of the test set.
:::

Depth was the main lever, but it did not come free. He et al. observed the *degradation problem*: a 56-layer plain network had higher training error than a 20-layer one on CIFAR-10. This is not overfitting, which would show as low training error and high test error. A deeper network can represent everything a shallower one can (let the extra layers compute the identity), so the problem is that gradient descent does not find those solutions. The second experiment reproduces it on a small problem.

## 5. Residual learning

:::thm Definition | Residual block
A residual block computes $x_{l+1} = x_l + F(x_l;\theta_l)$, where $F$, the *residual*, is a small network, for example $F(x) = V\,\sigma(Wx + b)$, possibly with normalization. When the dimensions differ, the skip uses a linear projection instead of the identity.
:::

:::fig resblock | A residual block. The block learns only the correction F(h) to its input; the skip connection carries h through unchanged.

:::thm Proposition | What the skip connection changes
1. A residual block with $V = 0$ is the identity. A plain block $x \mapsto W_2\,\sigma(W_1x + b_1) + b_2$ with ReLU can also represent the identity on $\mathbb{R}^d$, for example with $W_1 = \binom{I}{-I}$, $W_2 = (I\ \ -I)$, but only at such special weights, far from a random initialization.
2. For a stack of residual blocks, $x_L = x_l + \sum_{i=l}^{L-1}F(x_i)$, and for a loss $\ell$,
$$\frac{\partial \ell}{\partial x_l} = \frac{\partial \ell}{\partial x_L}\Bigl(I + \frac{\partial}{\partial x_l}\sum_{i=l}^{L-1}F(x_i)\Bigr).$$
The gradient reaches every block through the identity term, without passing through any other block's Jacobian.
3. If each block's Jacobian is $I + \varepsilon_lA_l$, then $\bigl\lVert\prod_l(I + \varepsilon_lA_l) - I\bigr\rVert \le e^{\sum_l \varepsilon_l\lVert A_l\rVert} - 1$.
:::proof Proof
(1) $\sigma(t) - \sigma(-t) = t$ for the ReLU. (2) Sum $x_{i+1} - x_i = F(x_i)$ over $i$, and differentiate with the chain rule. (3) Expand the product: it is $I$ plus a sum over nonempty subsets $S$ of products of the $\varepsilon_lA_l$, $l \in S$; by submultiplicativity the norm of the sum is at most $\prod_l(1 + \varepsilon_l\lVert A_l\rVert) - 1 \le e^{\sum_l\varepsilon_l\lVert A_l\rVert} - 1$.
:::

A plain network's input–output Jacobian is a product of $L$ matrices $D_lW_l$ (with $D_l$ the diagonal ReLU masks). With random weights, the logarithm of its norm along a direction behaves like a random walk whose spread grows with depth, so some directions are amplified and others suppressed by large factors; the He initialization of week 4 keeps the average right, not the spread. A residual network whose branches start small has a Jacobian close to $I$, by part 3, and gradient descent starts from a well-conditioned map and learns corrections.

:::thm Heuristic | Why residual learning works
If the best function for a block to compute is close to the identity, which is plausible for a network with many blocks that each refine a representation a little, then learning a small residual is easier than learning the whole map from a random start. Weight decay and small initialization pull $F$ towards 0, that is, the block towards the identity: the default of a residual block is to do no harm.
:::

:::thm Empirical | Residual networks behave like ensembles of shallower paths (Veit, Wilber and Belongie 2016)
Unrolling the sums gives $2^L$ paths through a residual network, most of them short. Deleting a single block from a trained ResNet changes its ImageNet error only slightly, while deleting a layer from VGG destroys it, and most of the gradient during training flows along paths of modest length. Residual networks therefore do not use their full depth the way a plain network must.
:::

ResNets also use batch normalization (Ioffe and Szegedy 2015) after each convolution. Normalization is not required: with a suitable rescaling of the initialization, residual networks of more than 100 layers train without it (Fixup; Zhang, Dauphin and Ma 2019).

## 6. What the filters learn

:::thm Empirical | Filters and features
The first-layer filters of AlexNet are oriented edge and bar detectors at several scales, and colour blobs, resembling Gabor filters and the receptive fields of simple cells in the visual cortex (Krizhevsky et al. 2012). Visualizing what maximally activates units in deeper layers shows textures, then object parts, then whole objects (Zeiler and Fergus 2014). ImageNet-trained CNNs rely more on texture than humans do: shown an image whose shape says cat and whose texture says elephant, they mostly answer elephant (Geirhos et al. 2019).
:::

A simple way to ask which pixels a prediction depends on is the *saliency map*, the gradient of the class score with respect to the input image (Simonyan, Vedaldi and Zisserman 2014), and many refinements of it. Whether such maps explain a model is disputed.

:::thm Contested | Do saliency maps show what the model uses?
Adebayo et al. (2018) proposed two sanity checks: the map should change when the model's weights are randomized, and when the training labels are randomized. Some popular methods, guided backpropagation among them, produced nearly the same maps for trained and randomized networks, so those maps reflect the image and the architecture more than anything the model learned. The plain gradient and some other methods passed the checks. Which attribution methods are faithful, and what faithful should mean, remains open.
:::

## Check yourself

:::check
Count the parameters of a $3\times3$ convolution from 3 to 64 channels, and from 64 to 128 channels. Compare with a dense layer from a $224\times224\times3$ image to 1,000 class scores.
---
$9\cdot3\cdot64 + 64 = 1{,}792$ and $9\cdot64\cdot128 + 128 = 73{,}856$, whatever the image size. The dense layer has $150{,}528\cdot1{,}000 + 1{,}000 = 150{,}529{,}000$ parameters, and it would need examples of each class at each position to learn what the convolution gets from weight sharing.
:::

:::check
On the cycle $\mathbb{Z}_4$, let $x = (1, 0, 0, 0)$ and apply max pooling with window 2 and stride 2, keeping positions $\{0, 1\}$ and $\{2, 3\}$. Compare the result for $x$ and for $T_1x$. Is the composition of an equivariant layer with this pooling equivariant?
---
For $x$ the pooled signal is $(1, 0)$; for $T_1x = (0, 1, 0, 0)$ it is again $(1, 0)$, and for $T_2x$ it is $(0, 1)$. So pooling with stride 2 is equivariant only for even shifts, with the shift halved; odd shifts are absorbed, which is the source of the aliasing in section 2. Global pooling over all positions is fully invariant.
:::

:::check
A network of $L$ residual blocks with linear residuals has Jacobian $(I + \varepsilon A)^L$. What happens as $L \to \infty$ with $\varepsilon = 1/L$, and how does that compare with a plain network whose layers have Jacobian $W$?
---
$(I + A/L)^L \to e^{A}$, a fixed invertible matrix, whatever the depth: the network behaves like the flow of an ordinary differential equation, which is the "neural ODE" reading of residual networks. A plain network has $W^L$, whose norm grows or decays like $\rho(W)^L$, where $\rho$ is the spectral radius, unless $W$ is exactly orthogonal.
:::
