Until now every example came with its answer. In reinforcement learning an agent acts, the world responds with a new situation and a number, and the only feedback is that number, often long after the action that earned it. This week sets up the problem as a Markov decision process, solves it exactly when the world is known, and then learns values from experience alone, by Monte Carlo averaging and by temporal differences. Start with the exact solution, on a small grid with a cliff.

:::four
**What is it trying to do?** Choose actions that maximize the total discounted reward over time, when actions have delayed consequences and the world is partly random: games, control, recommendation, and the fine-tuning of language models from feedback (week 13).
**Why can it be done this way?** If the state summarizes the past (the Markov property), the value of a state satisfies a one-step recursion, Bellman's equation, whose operator is a contraction; so values can be computed by iteration when the model is known (section 2), and estimated from samples when it is not (sections 3 and 4).
**Why should it be done this way?** A value function turns a long-horizon problem into a sequence of one-step decisions: act greedily with respect to the optimal values and you act optimally. Monte Carlo methods need no model and no Markov property; temporal-difference methods also need no model and learn during an episode, with lower variance (section 4).
**What comes out?** Exact optimal play for small problems such as Blackjack, Q-learning, and with neural networks as value functions, Atari from pixels and the AlphaGo line (section 6). Two experiments: the exact optimal Blackjack strategy and what Monte Carlo control learns, and Monte Carlo against TD on a random walk.
:::

## 1. Markov decision processes

:::fig mdploop | The agent and its environment. At each step the agent observes the state, chooses an action from its policy, and receives a reward and the next state. The goal is a large expected return, the discounted sum of future rewards.

:::thm Definition | Markov decision process
A finite MDP consists of sets of states $\mathcal S$, actions $\mathcal A$ and rewards $\mathcal R \subset \mathbb R$, dynamics $p(s', r \mid s, a)$, the probability of next state $s'$ and reward $r$ after action $a$ in state $s$, and a discount $\gamma \in [0, 1)$. A *policy* $\pi(a \mid s)$ chooses actions. The *return* from time $t$ is $G_t = \sum_{k \ge 0}\gamma^k R_{t+k+1}$; in episodic tasks the sum stops at the end of the episode and $\gamma = 1$ is allowed.
:::

The Markov property is the assumption that $p$ depends on the past only through $(s, a)$: the state must contain everything relevant. In Blackjack the state is the player's sum, the dealer's card and whether an ace counts as 11; the order in which the cards came does not matter (with an infinite deck).

:::thm Definition | Value functions
$$\begin{aligned}v_\pi(s) &= \mathbb{E}_\pi[G_t \mid S_t = s],\\ q_\pi(s, a) &= \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a],\end{aligned}$$
and the optimal ones $v_*(s) = \max_\pi v_\pi(s)$, $q_*(s, a) = \max_\pi q_\pi(s, a)$.
:::

The task splits in two. *Prediction*: given $\pi$, find $v_\pi$. *Control*: find a policy with the largest values. Since $G_t = R_{t+1} + \gamma G_{t+1}$, conditioning on one step gives the *Bellman equation*
$$v_\pi(s) = \sum_a \pi(a \mid s)\sum_{s', r}p(s', r \mid s, a)\bigl[r + \gamma v_\pi(s')\bigr],$$
a linear system with one equation per state, whose solution is $v_\pi$.

## 2. Bellman's optimality equation and dynamic programming

Define the *Bellman optimality operator* on functions $V: \mathcal S \to \mathbb R$ by
$$(TV)(s) = \max_a \sum_{s', r}p(s', r \mid s, a)\bigl[r + \gamma V(s')\bigr].$$

:::thm Theorem | $T$ is a $\gamma$-contraction
For all $V, U$, $\ \|TV - TU\|_\infty \le \gamma\,\|V - U\|_\infty$, where $\|V\|_\infty = \max_s |V(s)|$.
:::proof Proof
For any functions $f, g$ of $a$, $|\max_a f(a) - \max_a g(a)| \le \max_a |f(a) - g(a)|$: if the left side is $\max f - \max g \ge 0$ and $a^*$ attains $\max f$, it is at most $f(a^*) - g(a^*)$. Apply this with $f(a) = \sum p\,[r + \gamma V(s')]$ and $g(a) = \sum p\,[r + \gamma U(s')]$: the rewards cancel and
$$\begin{aligned}&|TV(s) - TU(s)|\\ &\quad\le \gamma\max_a \sum_{s', r}p(s', r \mid s, a)\,|V(s') - U(s')|\\ &\quad\le \gamma\,\|V - U\|_\infty,\end{aligned}$$
because the probabilities sum to 1.
:::

What follows, by Banach's fixed-point theorem on the complete space $\mathbb R^{\mathcal S}$: $T$ has exactly one fixed point, which is $v_*$; *value iteration* $V_{k+1} = TV_k$ converges to it from any start, with $\|V_k - v_*\|_\infty \le \gamma^k\|V_0 - v_*\|_\infty$; and the changes are a usable stopping rule, since $\|V_{k+1} - v_*\|_\infty \le \frac{\gamma}{1 - \gamma}\|V_{k+1} - V_k\|_\infty$. The widget shows the largest change shrinking by at most $\gamma$ per sweep. The same argument without the max shows that the operator of the Bellman equation for $v_\pi$ is a contraction too.

:::thm Theorem | Policy improvement
If $\pi'$ is greedy with respect to $v_\pi$, that is, $\pi'(s) \in \arg\max_a q_\pi(s, a)$ for every $s$, then $v_{\pi'}(s) \ge v_\pi(s)$ for every $s$; and if equality holds everywhere, $v_\pi = v_*$.
:::proof Proof sketch
$v_\pi(s) \le q_\pi(s, \pi'(s)) = \mathbb{E}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s, A_t = \pi'(s)]$. Apply the same inequality to $v_\pi(S_{t+1})$ and keep unrolling: the right side becomes $\mathbb{E}_{\pi'}[R_{t+1} + \gamma R_{t+2} + \cdots] = v_{\pi'}(s)$. If $v_{\pi'} = v_\pi$, then $v_\pi = Tv_\pi$, and the fixed point is unique.
:::

*Policy iteration* alternates the two: evaluate $\pi$ (solve the linear system), make it greedy, repeat. With finitely many policies and strict improvement until the end, it stops after finitely many rounds, in practice very few. Both methods need the model $p$, and a sweep costs $|\mathcal S|^2|\mathcal A|$ operations, which is why Bellman called the growth of the state space the *curse of dimensionality*. For Blackjack the model is known exactly, and the first experiment solves it.

## 3. Monte Carlo methods

Without a model, estimate values by averaging returns that were actually observed.

:::thm Proposition | Monte Carlo prediction
Run episodes with $\pi$. The *first-visit* estimate of $v_\pi(s)$, the average of the returns that followed the first visit to $s$ in each episode, is an average of independent, identically distributed samples of $G_t$ given $S_t = s$; it is unbiased, and by the law of large numbers it converges to $v_\pi(s)$ as the number of episodes grows, with error of order $1/\sqrt{n}$.
:::

Monte Carlo methods need no model and do not even need the Markov property, but they need episodes that end, and they learn only at the end. For control, estimate $q$ rather than $v$: choosing greedily from $v$ needs the model to look one step ahead, choosing greedily from $q$ does not. Then alternate as in policy iteration, but with sampled estimates: after each episode, update $Q$ at the pairs visited and make the policy greedy there.

:::thm Heuristic | Exploration
A greedy policy never tries the actions it currently thinks are worse, so their estimates never improve. *Exploring starts*: begin each episode in a random state with a random first action, so every pair is tried infinitely often. Where that is impossible, use an $\varepsilon$-*greedy* policy, which takes a random action with probability $\varepsilon$; it then converges to the best $\varepsilon$-greedy policy, not the best policy.
:::

The first experiment runs Monte Carlo control with exploring starts on Blackjack, the course's Colab task, and compares the policy it learns with the exact one.

## 4. Temporal-difference learning

Monte Carlo moves $V(S_t)$ toward the return $G_t$. TD(0) moves it toward a one-step target that uses the current estimate of the next state (Sutton 1988):
$$V(S_t) \leftarrow V(S_t) + \alpha\bigl[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\bigr].$$
The bracket is the *TD error* $\delta_t$. TD needs no model, like Monte Carlo, and updates after every step, like dynamic programming, using its own estimates: it *bootstraps*.

:::fig backups | What each method backs up. Dynamic programming averages over all actions and successors for one step, using the model. Monte Carlo samples one episode to the end. TD samples one step and then trusts the current estimate.

:::thm Heuristic | Bias and variance
The Monte Carlo target $G_t$ is unbiased for $v_\pi(S_t)$ but carries the randomness of every later step. The TD target $R_{t+1} + \gamma V(S_{t+1})$ carries the randomness of one step only, but is biased as long as $V \ne v_\pi$. In tabular problems the bias disappears as $V$ converges, and TD(0) with suitable step sizes converges to $v_\pi$ (Sutton 1988; Dayan 1992). In practice TD usually learns faster; no theorem says it must.
:::

A cleaner comparison trains both methods to convergence on a fixed batch of episodes.

:::thm Proposition | What batch Monte Carlo and batch TD converge to
On a fixed set of episodes, repeated small Monte Carlo updates converge to the average return observed after each state, the values that minimize the squared error on the observed returns. Repeated small TD(0) updates converge to the values of the Markov chain whose transition probabilities and rewards are the observed frequencies, the *certainty-equivalence* estimate: the exact $v$ of the maximum-likelihood model.
:::proof Proof sketch
Batch TD converges to the $V$ at which the accumulated updates vanish: for every state $s$, $\sum_{t: S_t = s}\bigl[R_{t+1} + \gamma V(S_{t+1}) - V(s)\bigr] = 0$. Divided by the number of visits, this says $V(s) = \hat r(s) + \gamma\sum_{s'}\hat p(s' \mid s)V(s')$ with the empirical averages $\hat r$, $\hat p$: the Bellman equation of the estimated chain. For Monte Carlo the same condition reads $\sum_{t: S_t = s}[G_t - V(s)] = 0$.
:::

When the world really is Markov, the certainty-equivalence estimate uses that fact, and the sample average does not. The second experiment shows the difference on a five-state random walk. Between the two extremes are $n$-step returns, which bootstrap after $n$ steps, and TD($\lambda$), which averages all of them with weights $(1 - \lambda)\lambda^{n-1}$; $\lambda = 0$ is TD(0) and $\lambda = 1$ is Monte Carlo.

## 5. SARSA, Q-learning and function approximation

For control, apply TD to $Q$. *SARSA* (Rummery and Niranjan 1994) uses the action the policy actually takes next:
$$\begin{aligned}\delta_t &= R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t),\\ Q(S_t, A_t) &\leftarrow Q(S_t, A_t) + \alpha\,\delta_t,\end{aligned}$$
and learns the value of the $\varepsilon$-greedy policy it follows. *Q-learning* (Watkins 1989) replaces $Q(S_{t+1}, A_{t+1})$ in $\delta_t$ by $\max_a Q(S_{t+1}, a)$, a sampled version of the optimality operator $T$, and learns $q_*$ whatever policy generated the data: it is *off-policy*.

:::thm Theorem | Convergence of tabular Q-learning (Watkins and Dayan 1992)
In a finite MDP, if every state–action pair is updated infinitely often and the step sizes satisfy $\sum_t \alpha_t = \infty$, $\sum_t \alpha_t^2 < \infty$ for each pair, then $Q$ converges to $q_*$ with probability 1.
:::

With many states, store $v$ or $q$ as a function $\hat v(s; w)$: linear in features, or a neural network. *Semi-gradient TD* updates $w \leftarrow w + \alpha\,\delta_t\nabla_w\hat v(S_t; w)$: it differentiates the prediction but not the target, so it is not the gradient of any fixed loss.

:::thm Theorem | On-policy linear TD (Tsitsiklis and Van Roy 1997)
With linear features and states sampled from the policy's own stationary distribution, TD(0) with Robbins–Monro step sizes converges with probability 1, to the fixed point of the Bellman operator followed by projection onto the span of the features in the norm weighted by that distribution. Its error is within a factor depending on $\gamma$ of the best linear approximation.
:::

:::thm Contested | The deadly triad
Sutton and Barto name three ingredients: function approximation, bootstrapping, and off-policy training. Any two are safe; with all three, values can diverge. Baird's counterexample (1995) is a seven-state MDP with linear features rich enough to represent the true values exactly, in which off-policy semi-gradient TD drives the weights to infinity. The projection and the off-policy distribution together can make the composite operator expansive. Q-learning with a neural network has all three, and no general convergence guarantee. Gradient-TD methods (Sutton et al. 2009) converge in the linear case at some cost in speed; how much the triad matters for large networks in practice, and why tricks such as target networks help, is still argued.
:::

## 6. Case studies: Atari, AlphaGo, AlphaZero

:::thm Empirical | Deep Q-networks (Mnih et al. 2013, 2015)
A convolutional network maps the last four Atari frames to $Q(s, a)$ for each joystick action and is trained by Q-learning on the clipped game score. Two changes made the triad manageable. *Experience replay* stores transitions and trains on random minibatches of them, which breaks the correlation between consecutive frames. A *target network*, a copy of the weights updated only every few thousand steps, supplies the target $\max_a Q(S_{t+1}, a)$, so the target does not move with every update. The 2013 paper beat earlier methods on six of seven games; the 2015 version played 49 games with one architecture and one set of hyperparameters, at the level of a professional tester on many of them.
:::

:::thm Empirical | AlphaGo (Silver et al. 2016)
A policy network was first trained by supervised learning to predict expert moves from about 30 million positions, then improved by policy-gradient self-play (week 13); a value network was trained to predict the winner of self-play games. Moves were chosen by Monte Carlo tree search, which expands promising moves according to the policy network and evaluates positions with the value network together with fast rollouts. It beat the European champion Fan Hui 5–0, the first win by a program against a professional on a full board without handicap, and Lee Sedol 4–1 in March 2016.
:::

:::fig azloop | The AlphaZero loop. A single network gives move probabilities p and a value v. The tree search uses them to choose moves in self-play, and is stronger than the network alone; the network is then trained to predict the search's move choices and the final result.

:::thm Definition | AlphaZero (Silver et al. 2017, 2018)
No human games and no rollouts: one network $f_\theta(s) = (p, v)$ and a tree search. Self-play games are played with the search, which produces at each position a move distribution $\pi$ sharper than $p$; at the end each position is labelled with the outcome $z \in \{-1, 0, 1\}$. The network is trained on
$$\ell(\theta) = (z - v)^2 - \pi^\top\log p + c\,\|\theta\|^2.$$
The search is a policy-improvement operator, as in section 2, and training the network to imitate it is the evaluation-and-update step; the value head is regressed on Monte Carlo returns $z$. The same algorithm and settings learned chess, shogi and Go, and defeated the strongest programs in each.
:::

## Check yourself

:::check
In a two-state MDP, state 1 gives reward 1 and moves to state 2; state 2 gives reward 0 and moves to state 1; there is one action and $\gamma = 0.9$. Find $v$, and say how many sweeps of value iteration from $V = 0$ guarantee an error below $0.01$.
---
$v(1) = 1 + 0.9\,v(2)$ and $v(2) = 0.9\,v(1)$, so $v(1) = 1/(1 - 0.81) \approx 5.263$ and $v(2) \approx 4.737$. The bound $\|V_k - v\|_\infty \le 0.9^k\,\|v\|_\infty = 0.9^k \cdot 5.263$ falls below $0.01$ when $k \ge \ln(0.0019)/\ln 0.9 \approx 59.5$, so $60$ sweeps.
:::

:::check
Why does Monte Carlo control estimate $q$ rather than $v$? What would greedy improvement with $v$ require?
---
Greedy improvement with $v$ means $\arg\max_a \sum_{s', r}p(s', r \mid s, a)[r + \gamma v(s')]$, which needs the dynamics $p$. With $q$ it is $\arg\max_a q(s, a)$, which needs nothing else. Model-free control therefore learns action values.
:::

:::check
Batch training on two episodes: A, 0, B, 0 (end) and B, 1 (end), with $\gamma = 1$. What do batch Monte Carlo and batch TD(0) give for $V(A)$ and $V(B)$?
---
Both give $V(B) = \frac12$, the average of the two returns that followed B. Monte Carlo gives $V(A) = 0$, the one return observed after A. TD gives $V(A) = 0 + V(B) = \frac12$, since in the estimated chain A always moves to B with reward 0. If the process is Markov, TD's answer uses more of the data. This is Sutton and Barto's Example 6.4 in miniature.
:::
