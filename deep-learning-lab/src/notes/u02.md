:::four
**What is it trying to do?** Put numbers on information: how surprising an outcome is, how uncertain a random variable is, how much one variable tells about another, and how far a model is from the truth. The unit throughout is the length of a description, in bits.
**Why can it be done this way?** Codes and probability distributions are the same thing up to rounding. The codeword lengths of a decodable code satisfy $\sum_x 2^{-\ell(x)} \le 1$, so $2^{-\ell}$ is a probability; conversely every distribution $p$ has a code with $\ell(x) \approx -\log_2 p(x)$, also for long messages coded in one piece (sections 4 and 5). A one-line convexity argument, Gibbs' inequality, then makes the true distribution the best code (section 3).
**Why should it be done this way?** The measure is forced. $-\log p$ is the only additive, monotone measure of surprise (section 1), the logarithmic loss is the only local scoring rule that rewards honest forecasts (section 3), and no lossless code beats the entropy on average (section 4).
**What comes out?** The cross-entropy loss of week 1 is a code length, and the gap between a model's loss and the entropy of its data is a KL divergence. A next-symbol predictor with arithmetic coding is a compressor, and a compressor is a model (sections 5 and 6). Two experiments: arithmetic coding done exactly, and the entropy of Shakespeare estimated by counting, first naively and then honestly (section 7).
:::

## 1. Information and entropy

:::thm Convention | Bits and nats
$\log$ means $\log_2$, and information is measured in bits. $\ln$ gives nats; one nat is $1/\ln 2 \approx 1.443$ bits. Training losses on this site are in nats, as PyTorch reports them. In sums, $0\log 0 = 0$.
:::

How much information is there in learning that an event of probability $p$ has happened? Call it $I(p)$. A rarer event should be more informative, and the information from two independent events should add up. That already determines $I$.

:::thm Proposition | Surprise is −log p
Let $I\colon (0,1] \to \mathbb{R}$ satisfy (i) $I(pq) = I(p) + I(q)$ for all $p, q$; (ii) $I$ is nonincreasing; (iii) $I(\frac12) = 1$. Then $I(p) = -\log_2 p$.
:::proof Proof
Put $f(t) = I(2^{-t})$ for $t \ge 0$. Then $f(s + t) = f(s) + f(t)$, $f$ is nondecreasing, and $f(1) = 1$. Additivity gives $f(0) = 0$, $f(m) = m$ for whole numbers $m$, and $n f(m/n) = f(m) = m$, so $f(r) = r$ for every rational $r \ge 0$. For real $t$ and rationals $r \le t \le s$, monotonicity gives $r \le f(t) \le s$; letting $r$ and $s$ tend to $t$ gives $f(t) = t$. Hence $I(p) = f(-\log_2 p) = -\log_2 p$. Some regularity like (ii) is needed: without it, $f(s+t) = f(s) + f(t)$ has wild solutions built from a Hamel basis of $\mathbb{R}$ over $\mathbb{Q}$.
:::

$-\log p(x)$ is the *surprisal* of the outcome $x$. Its average is the entropy.

:::thm Definition | Entropy
For a random variable $X$ with values in a finite set $\mathcal X$ and distribution $p$,
$$\begin{aligned} H(X) = H(p) &= -\sum_{x} p(x)\log p(x) \\ &= \mathbb{E}\bigl[-\log p(X)\bigr]. \end{aligned}$$
It depends only on the probabilities, not on the values.
:::

A fair coin has $H = 1$ bit, a fair die $\log 6 \approx 2.585$ bits. A coin with heads probability $p$ has the *binary entropy* $h(p) = -p\log p - (1-p)\log(1-p)$, for example $h(0.11) \approx 0.50$ and $h(0.01) \approx 0.081$. The four letters of the figure, with probabilities $(\frac12, \frac14, \frac18, \frac18)$, have $H = \frac12\cdot1 + \frac14\cdot2 + 2\cdot\frac18\cdot3 = 1.75$ bits.

:::thm Proposition | Range of the entropy
$0 \le H(X) \le \log\lvert\mathcal X\rvert$. The lower bound is attained exactly when $X$ is constant, the upper bound exactly when $X$ is uniform.
:::proof Proof
Each term $-p\log p$ is nonnegative and vanishes only for $p \in \{0, 1\}$. For the upper bound, apply Gibbs' inequality (section 3) with $q$ uniform: $0 \le D(p\,\|\,q) = \log\lvert\mathcal X\rvert - H(p)$, with equality only for $p = q$.
:::

Read $H(X)$ as the number of yes/no questions needed, on average, to find out $X$ when the questions are chosen well: first ask whether $X$ lies in a set of probability about $\frac12$, then split again. Section 4 makes this exact to within one question, because a strategy of questions is a prefix code.

Is $H$ the right way to average surprise, or merely one way? Shannon (1948) showed that a few requirements force it. Faddeev's version needs the fewest.

:::thm Theorem | Characterization of entropy (Faddeev 1956)
For each $n \ge 2$ let $H_n$ be a function on probability vectors of length $n$ such that
1. each $H_n$ is symmetric in its arguments;
2. $H_2(p, 1-p)$ is continuous in $p$, and $H_2(\frac12, \frac12) = 1$;
3. (grouping) whenever $s = p_1 + p_2 > 0$,
$$\begin{aligned} H_n(p_1, \dots, p_n) &= H_{n-1}(s, p_3, \dots, p_n) \\ &\quad + s\, H_2\Bigl(\frac{p_1}{s}, \frac{p_2}{s}\Bigr). \end{aligned}$$

Then $H_n(p) = -\sum_i p_i \log_2 p_i$ for all $n$ and $p$.
:::proof Proof sketch
Grouping says: to learn the outcome, first learn whether it is one of the first two, then which one; the second question is asked only with probability $p_1 + p_2$. Write $F(n) = H_n(\frac1n, \dots, \frac1n)$. Grouping $mn$ equally likely outcomes into $m$ blocks of $n$ gives $F(mn) = F(m) + F(n)$. Grouping, applied repeatedly, also splits off a single outcome: $F(n) - \frac{n-1}{n}F(n-1) = H_2(\frac1n, \frac{n-1}{n})$, which tends to $H_2(0, 1)$ by continuity. And $H_2(0,1) = 0$: expand $H_3(\frac12, \frac12, 0)$ by grouping once directly and once after a permutation, and compare. A number-theoretic lemma then gives $F(n) = c\log n$, and $c = 1$ by normalization. For rational $p_i = k_i/N$, split $N$ equally likely outcomes into blocks of sizes $k_i$; grouping gives $F(N) = H_n(p) + \sum_i p_i F(k_i)$, that is, $H_n(p) = -\sum_i p_i \log p_i$. Continuity extends this to all $p$, first for $n = 2$, then for every $n$ by grouping.
:::

## 2. Conditional entropy and mutual information

For a pair $(X, Y)$ with joint distribution $p(x, y)$, the joint entropy $H(X, Y)$ is the entropy of the pair as one random variable.

:::thm Definition | Conditional entropy and mutual information
$$\begin{aligned} H(Y\mid X) &= \sum_x p(x)\, H(Y\mid X = x) \\ &= \mathbb{E}\bigl[-\log p(Y\mid X)\bigr] \end{aligned}$$
is the uncertainty about $Y$ that remains once $X$ is known, averaged over $X$; and
$$I(X;Y) = H(Y) - H(Y\mid X)$$
is the reduction in uncertainty about $Y$ from learning $X$. Conditional versions are defined in the same way, for example $I(X;Y\mid Z) = H(Y\mid Z) - H(Y\mid X, Z)$.
:::

:::thm Proposition | Chain rules
1. $H(X, Y) = H(X) + H(Y\mid X)$, and more generally $H(X_1, \dots, X_n) = \sum_{t=1}^n H(X_t \mid X_1, \dots, X_{t-1})$.
2. $I(X;Y) = H(X) + H(Y) - H(X, Y) = \sum_{x,y} p(x,y)\log\dfrac{p(x,y)}{p(x)\,p(y)}$. In particular $I(X;Y) = I(Y;X)$.
3. $I(X; (Y, Z)) = I(X;Z) + I(X;Y\mid Z)$.
:::proof Proof
(1) Take the expectation of $-\log p(x, y) = -\log p(x) - \log p(y\mid x)$, and induct on $n$. (2) Substitute (1) into the definition and write each entropy as the expectation of a logarithm. (3) By (2) applied to the conditional distributions, $I(X;Y\mid Z) = H(X\mid Z) - H(X\mid Y, Z)$; add $I(X;Z) = H(X) - H(X\mid Z)$.
:::

The general chain rule is the factorization that autoregressive models use (week 7): $p(x_1, \dots, x_n) = \prod_t p(x_t\mid x_{<t})$. The loss of such a model, summed over a text, is a sum of conditional surprisals.

:::fig infovenn | For two variables the identities of this section are additivity of areas. The circles have areas H(X) and H(Y), their union H(X, Y), the overlap I(X; Y), and the two crescents H(X | Y) and H(Y | X). For three variables the picture misleads, because the central region can be negative (second check question).

Two inequalities need Gibbs' inequality from section 3.

:::thm Proposition | Information is nonnegative
$I(X;Y) \ge 0$, that is, $H(Y\mid X) \le H(Y)$, with equality if and only if $X$ and $Y$ are independent. Likewise $I(X;Y\mid Z) \ge 0$.
:::proof Proof
By (2) of the chain rules, $I(X;Y) = D(p_{XY}\,\|\,p_X\otimes p_Y)$, which is nonnegative and vanishes only if $p_{XY} = p_X\otimes p_Y$ (Gibbs' inequality, section 3). $I(X;Y\mid Z)$ is the average over $z$ of the same divergence for the distributions conditioned on $Z = z$.
:::

"Conditioning reduces entropy" holds only on average. Learning a particular value can raise the uncertainty. Let $X$ be a fair bit; if $X = 0$ then $Y = 0$, and if $X = 1$ then $Y$ is a fair bit. Then $H(Y) = h(\frac14) \approx 0.811$ and $H(Y\mid X = 1) = 1$, while $H(Y\mid X) = \frac12$.

:::thm Theorem | Data processing inequality
If $X \to Y \to Z$ is a Markov chain, that is, $Z$ depends on $X$ only through $Y$, then $I(X;Z) \le I(X;Y)$. In particular $I(X; f(Y)) \le I(X;Y)$ for every function $f$.
:::proof Proof
By the chain rule (3) used in two orders, $I(X;(Y,Z)) = I(X;Z) + I(X;Y\mid Z) = I(X;Y) + I(X;Z\mid Y)$. The Markov property is $I(X;Z\mid Y) = 0$, and $I(X;Y\mid Z) \ge 0$.
:::

So a later layer of a network carries no more information about the input than an earlier one. Whether training makes networks discard information about their input, and whether that has anything to do with generalization, is disputed.

:::thm Contested | Do networks compress their inputs? (the information bottleneck)
Shwartz-Ziv and Tishby (2017) estimated the mutual information between each layer and the input while training small tanh networks, and reported two phases: it first rises with the fit, then falls. They linked this "compression" to generalization. Saxe et al. (2018) found the compression phase with tanh but not with ReLU, and networks that generalize without it. The quantity itself is delicate: for a deterministic network with continuous inputs, the mutual information between the input and a layer is infinite, or constant during training, so what gets measured depends on how activations are binned or noised (Goldfeld et al. 2019). Whether a well-defined form of compression accompanies generalization is open.
:::

One more definition prepares section 6. A text is better modelled as a long dependent sequence than as one draw.

:::thm Theorem | Entropy rate of a stationary process
Let $X_1, X_2, \dots$ be a stationary process with values in a finite set. Then $a_n = H(X_n\mid X_1, \dots, X_{n-1})$ and $\frac1n H(X_1, \dots, X_n)$ are both nonincreasing in $n$ and converge to the same limit $\mathcal H$, the *entropy rate*.
:::proof Proof
Conditioning on more cannot raise entropy (on average), and stationarity shifts indices: $a_{n+1} = H(X_{n+1}\mid X_1, \dots, X_n) \le H(X_{n+1}\mid X_2, \dots, X_n) = a_n$. So $a_n$ decreases to a limit $\mathcal H \ge 0$. By the chain rule, $\frac1n H(X_1, \dots, X_n) = \frac1n\sum_{t\le n} a_t$, an average of a nonincreasing sequence; it is nonincreasing and converges to the same limit.
:::

For a text, $a_{k+1}$ is the entropy of the next character given the previous $k$, and it decreases to $\mathcal H$ as $k$ grows. The second experiment estimates these numbers for Shakespeare.

## 3. KL divergence and Gibbs' inequality

:::thm Definition | Kullback–Leibler divergence and cross-entropy
For distributions $p$ and $q$ on $\mathcal X$,
$$\begin{aligned} D(p\,\|\,q) &= \sum_x p(x)\log\frac{p(x)}{q(x)}, \\ H(p, q) &= -\sum_x p(x)\log q(x) \\ &= H(p) + D(p\,\|\,q), \end{aligned}$$
with $0\log\frac0q = 0$ and $p\log\frac p0 = +\infty$ for $p > 0$. The *cross-entropy* $H(p,q)$ is the average surprisal, under the model $q$, of outcomes that actually come from $p$.
:::

The figure at the top computed $H(p, q)$: the cost per letter when the letters come from $p$ and the code is built from your guess $q$. The smallest value was at $q = p$.

:::thm Theorem | Gibbs' inequality
$D(p\,\|\,q) \ge 0$, with equality if and only if $p = q$. Equivalently, $H(p, q) \ge H(p)$: the expected surprisal under a model is smallest when the model is the truth.
:::proof Proof
If $q(x) = 0 < p(x)$ for some $x$, then $D = \infty$. Otherwise use $\ln u \le u - 1$, with equality only at $u = 1$. Summing over the $x$ with $p(x) > 0$,
$$\begin{aligned} -\ln 2\cdot D(p\,\|\,q) &= \sum p(x)\ln\frac{q(x)}{p(x)} \\ &\le \sum \bigl(q(x) - p(x)\bigr) \\ &= \sum q(x) - 1 \le 0. \end{aligned}$$
Equality forces $q(x) = p(x)$ wherever $p(x) > 0$, and then no mass of $q$ is left for the other $x$.
:::

The inequality has a second reading, as a statement about forecasts. A forecaster announces a distribution $q$ and is charged $S(q, x)$ when $x$ happens. The charge is *strictly proper* if, when outcomes come from $p$, the expected charge $\sum_x p(x)S(q,x)$ is smallest only at $q = p$: honesty is the unique best policy. Gibbs' inequality says that $S(q, x) = -\log q(x)$ is strictly proper.

:::thm Theorem | The logarithmic score is the only local proper score (Bernardo 1979)
Let there be at least three outcomes, and let $S(q, x) = s(q(x))$ depend only on the probability given to the outcome that happened, with $s$ differentiable on $(0, 1)$. If $S$ is strictly proper, then $s(t) = a - b\log t$ for constants $a$ and $b > 0$.
:::proof Proof sketch
At $q = p$ the expected charge $\sum_x p(x)\,s(q(x))$ must be stationary under changes of $q$ that keep $\sum_x q(x) = 1$, so $p(x)\,s'(p(x))$ is the same for every $x$. With three outcomes, $p = (t, u, 1 - t - u)$ shows that $t\,s'(t) = u\,s'(u)$ whenever $t + u < 1$, so $t\,s'(t)$ is a constant on $(0,1)$ and $s$ is a multiple of $\log t$ plus a constant. A minimum rather than a maximum needs $b > 0$. With two outcomes every score is local, and others, such as the squared error, are also proper.
:::

So the loss in week 1 is not one choice among many: if a loss is to reward calibrated probabilities and to look only at the probability of what happened, it is the log loss.

$D$ is not a distance: it is not symmetric, and it does not satisfy the triangle inequality. For $p = (0.9, 0.1)$ and $q = (0.99, 0.01)$, $D(p\,\|\,q) \approx 0.208$ bits but $D(q\,\|\,p) \approx 0.103$ bits; the first experiment measures both as wasted bits. And $D(p\,\|\,q) = \infty$ as soon as $q$ rules out something that $p$ allows, while the reverse divergence can stay finite. Which one is minimized matters when the model cannot match the truth.

:::fig klfit | Fitting one Gaussian q to a two-humped p. Minimizing D(p ‖ q), which is what maximum likelihood does (section 6), spreads q over both humps: wherever p has mass, q must not be small. Minimizing D(q ‖ p) puts q on one hump: wherever p is small, q must be small too.

:::thm Heuristic | Mass-covering and mode-seeking
When the model family cannot represent $p$, minimizing $D(p\,\|\,q)$ over $q$ tends to give a $q$ that covers all of $p$ and is too broad; minimizing $D(q\,\|\,p)$ tends to give a $q$ that sits on part of $p$ and is too narrow. Maximum likelihood is of the first kind. Variational inference, which week 9 uses for variational autoencoders, is of the second. The figure is one computed instance; in general the outcome depends on the family.
:::

$D(p\,\|\,q) = \mathbb{E}_p\bigl[\log\frac{p(X)}{q(X)}\bigr]$ is also the average log-likelihood ratio: the evidence that one observation provides, on average, for $p$ against $q$ when $p$ is true.

:::thm Theorem | Stein's lemma (Cover and Thomas, Theorem 11.8.3)
Observe $X_1, \dots, X_n$ i.i.d. from $p$ or from $q$, with $D(p\,\|\,q) < \infty$, and decide which. Among tests that reject $p$ wrongly with probability at most $\varepsilon \in (0, 1)$, the smallest probability of accepting $p$ when the truth is $q$ is $2^{-nD(p\,\|\,q) + o(n)}$.
:::

## 4. Codes and the source coding theorem

A binary *code* assigns a codeword $c(x) \in \{0,1\}^*$ to each symbol; a message is coded by concatenating codewords. The code is *uniquely decodable* if different messages give different bit strings, and a *prefix code* if no codeword is a prefix of another. A prefix code can be decoded on the fly: read bits until they form a codeword. A strategy of yes/no questions is a prefix code, its codewords the sequences of answers.

:::thm Theorem | Kraft–McMillan inequality
1. (McMillan) The codeword lengths of every uniquely decodable code satisfy $\sum_x 2^{-\ell(x)} \le 1$.
2. (Kraft) Conversely, if whole numbers $\ell(x)$ satisfy $\sum_x 2^{-\ell(x)} \le 1$, there is a prefix code with these lengths.
:::proof Proof
(2) A codeword $b_1\dots b_\ell$ names the dyadic interval $[0.b_1\dots b_\ell,\ 0.b_1\dots b_\ell + 2^{-\ell})$, and one codeword is a prefix of another exactly when the second interval lies inside the first. So a prefix code is a set of disjoint dyadic intervals. Order the lengths $\ell_1 \le \ell_2 \le \dots$ and give the $i$-th symbol the interval of length $2^{-\ell_i}$ that starts at $a_i = \sum_{j<i} 2^{-\ell_j}$. Since $\ell_j \le \ell_i$ for $j < i$, $a_i$ is a multiple of $2^{-\ell_i}$, so the interval is dyadic. The intervals are consecutive, hence disjoint, and they end before $\sum_j 2^{-\ell_j} \le 1$.

(1) Let $L = \max_x \ell(x)$ and $k \ge 1$. Expanding the power,
$$\Bigl(\sum_x 2^{-\ell(x)}\Bigr)^k = \sum_{m=1}^{kL} A_m\, 2^{-m},$$
where $A_m$ is the number of messages of $k$ symbols whose code has $m$ bits. Unique decodability makes these $A_m$ codes distinct strings of $m$ bits, so $A_m \le 2^m$ and the sum is at most $kL$. A number whose $k$-th power is at most $kL$ for every $k$ is at most 1.
:::

A decodable code is therefore the same thing as a subprobability distribution $r(x) = 2^{-\ell(x)}$ with values rounded to powers of two: a long codeword is a small probability.

:::fig codetree | The code A = 0, B = 10, C = 110, D = 111 as a tree of yes/no answers, and as the dyadic intervals of the proof of Kraft's inequality: a codeword of length ℓ owns an interval of length 2⁻ˡ, and prefix-free means disjoint. For the source of the figure at the top, p = (1/2, 1/4, 1/8, 1/8), each leaf sits at depth −log p, and the expected length is the entropy, 1.75 bits.

:::thm Theorem | Source coding theorem, one symbol at a time (Shannon 1948)
Let $X$ have distribution $p$.
1. Every uniquely decodable code satisfies $\mathbb{E}\,\ell(X) \ge H(X)$, with equality if and only if $\ell(x) = -\log p(x)$ for every $x$.
2. The *Shannon code*, with lengths $\ell(x) = \lceil -\log p(x)\rceil$ for the $x$ with $p(x) > 0$, is a prefix code with $\mathbb{E}\,\ell(X) < H(X) + 1$.
:::proof Proof
(1) Let $S = \sum_x 2^{-\ell(x)}$, at most 1 by McMillan, and $r(x) = 2^{-\ell(x)}/S$. Then
$$\begin{aligned} \mathbb{E}\,\ell(X) - H(X) &= \sum_x p(x)\log\frac{p(x)}{2^{-\ell(x)}} \\ &= D(p\,\|\,r) + \log\frac1S \;\ge\; 0, \end{aligned}$$
with equality if and only if $p = r$ and $S = 1$. (2) $\sum_x 2^{-\lceil -\log p(x)\rceil} \le \sum_x p(x) = 1$, so Kraft gives a prefix code, and $\lceil -\log p\rceil < -\log p + 1$.
:::

:::thm Proposition | A code built for the wrong distribution costs D(p ‖ q)
If the Shannon code is built for $q$, with $\ell(x) = \lceil -\log q(x)\rceil$, and $X$ has distribution $p$, then
$$\begin{aligned} \mathbb{E}\,\ell(X) &\ge H(p) + D(p\,\|\,q), \\ \mathbb{E}\,\ell(X) &< H(p) + D(p\,\|\,q) + 1. \end{aligned}$$
:::proof Proof
$-\log q(x) \le \ell(x) < -\log q(x) + 1$, and $\mathbb{E}[-\log q(X)] = H(p, q) = H(p) + D(p\,\|\,q)$.
:::

This is the operational meaning of the divergence: $D(p\,\|\,q)$ is the number of bits per symbol wasted by believing $q$ when the truth is $p$. The figure at the top showed it; the first experiment measures it for a model that is wrong by a factor of ten.

The "+1" matters for skewed sources. Huffman's algorithm (1952), which repeatedly merges the two least likely symbols, gives a prefix code of the smallest possible expected length (Cover and Thomas, Theorem 5.8.1). Still, every codeword has at least one bit. If $p(B) = 0.01$, the entropy is $0.081$ bits per letter, but every letter-by-letter code spends at least 1 bit per letter. Coding blocks of $k$ letters as single symbols brings the overhead below $1/k$ bits per letter, at the cost of a code table with $\lvert\mathcal X\rvert^k$ entries. For a stationary ergodic source the cost per letter then tends to the entropy rate (Shannon–McMillan–Breiman theorem; Cover and Thomas, chapter 16). Arithmetic coding achieves this without the table.

## 5. Arithmetic coding

Let a model give probabilities $q(a\mid x_{<t})$ for the next symbol after the symbols $x_{<t} = x_1, \dots, x_{t-1}$. Any predictor will do: a table of counts, or a network. Fix an order on the alphabet and write $F(a\mid x_{<t}) = \sum_{b < a} q(b\mid x_{<t})$ for the probability of the symbols before $a$. Start with the interval $[0, 1)$. On reading $x_t$, replace the current interval $[\mathrm{low}, \mathrm{low} + w)$ by the part that belongs to $x_t$:
$$\begin{aligned} \mathrm{low} &\leftarrow \mathrm{low} + w\, F(x_t\mid x_{<t}), \\ w &\leftarrow w\, q(x_t\mid x_{<t}). \end{aligned}$$
After $n$ symbols the interval $I(x)$ has width $Q(x) = \prod_t q(x_t\mid x_{<t})$, the probability that the model gives to the whole message, and the intervals of the different messages of length $n$ tile $[0, 1)$.

:::fig arith | Coding the message B, A, D with the model of the figure at the top, q = (1/2, 1/4, 1/8, 1/8) for A, B, C, D at every step. Each letter keeps its share of the current interval: B keeps [1/2, 3/4), A then the lower half of that, D then the top eighth. The final interval [39/64, 40/64) has width 1/4 · 1/2 · 1/8 = 1/64, and six bits name it: 0.100111 in binary. The code length is the sum of the surprisals, 2 + 1 + 3.

:::thm Proposition | Arithmetic coding is within two bits of the model's surprisal
For messages of a fixed length $n$, let $\ell(x) = \lceil -\log Q(x)\rceil + 1$. The interval $I(x)$ contains a dyadic interval $[k2^{-\ell(x)}, (k+1)2^{-\ell(x)})$; the $\ell(x)$ binary digits of $k$ form a prefix code, and
$$\begin{aligned} \ell(x) &< -\log Q(x) + 2 \\ &= \sum_{t=1}^n -\log q(x_t\mid x_{<t}) + 2. \end{aligned}$$
:::proof Proof
Write $I(x) = [\mathrm{low}, \mathrm{low} + Q)$ and $\ell = \ell(x)$, so that $2^{-\ell} \le Q/2$. Let $k = \lceil \mathrm{low}\cdot 2^{\ell}\rceil$. Then $\mathrm{low} \le k2^{-\ell} < \mathrm{low} + 2^{-\ell}$, so $(k+1)2^{-\ell} < \mathrm{low} + 2\cdot2^{-\ell} \le \mathrm{low} + Q$. The dyadic intervals chosen for different messages lie in disjoint intervals $I(x)$, so they are disjoint, which is the prefix property (proof of Kraft's inequality, section 4).
:::

The decoder runs the same model. It finds which part of $[0, 1)$ contains the number $0.b_1b_2\dots b_\ell$, outputs that symbol, asks the model for the next probabilities, and repeats. Two consequences. First, any predictor that outputs probabilities becomes a compressor in this way, and its compressed size is its summed surprisal up to two bits. Second, decompression needs the model too. Practical coders (Rissanen 1976 and Pasco 1976; the standard implementation is Witten, Neal and Cleary 1987) hold the interval in fixed-precision integers and emit leading bits as soon as they are settled, and the rounding costs a little at each symbol. The first experiment keeps exact fractions instead, which is possible for ten thousand letters and shows the proposition without rounding.

:::thm Proposition | A decoder fed random bits is a sampler
If $U$ is uniform on $[0, 1)$ and the decoder reads $U$ in place of a codeword, the message it outputs has distribution $Q$.
:::proof Proof
The decoder outputs $x$ exactly when $U \in I(x)$, an event of probability $\lvert I(x)\rvert = Q(x)$.
:::

## 6. Generative models are compressors

Train a model $q_\theta(x_t\mid x_{<t})$ by minimizing the cross-entropy loss, the average of $-\ln q_\theta(x_t\mid x_{<t})$ over the training text. Sections 4 and 5 say what that number is.

:::thm Proposition | The loss is a file size
1. If a model has loss $L$ nats per symbol on a text of $n$ symbols, arithmetic coding with the model compresses the text to fewer than $nL/\ln 2 + 2$ bits, and decompresses it exactly given the model.
2. Conversely, a lossless compressor $C$ for texts of length $n$ whose outputs form a prefix code defines the subprobability $r(x) = 2^{-\lvert C(x)\rvert}$, and its expected output length on texts from $p$ is the cross-entropy $H(p, r)$.
3. Let the text come from a stationary source and let $p_n$, $q_n$ be the source's and the model's distributions of texts of length $n$. The expected loss per symbol, in bits, is $\frac1n H(p_n) + \frac1n D(p_n\,\|\,q_n) \ge \mathcal H$, the entropy rate of section 2.
:::proof Proof
(1) is the proposition of section 5, with $-\log_2 Q = nL/\ln 2$. (2) is Kraft–McMillan read backwards: $\lvert C(x)\rvert = -\log r(x)$, and $\sum_x r(x) \le 1$. (3) The expected summed loss is $H(p_n, q_n) = H(p_n) + D(p_n\,\|\,q_n)$; the divergence is nonnegative by Gibbs, and $\frac1n H(p_n) = \frac1n H(X_1, \dots, X_n)$ decreases to $\mathcal H$ (theorem in section 2).
:::

So a good compressor and a good generative model are the same object, scored by the same number: a model is a compressor through arithmetic coding, a compressor is a model through Kraft's inequality, and the loss in nats per symbol divided by $\ln 2$ is the compression rate in bits per symbol. Part 3 says what no amount of training can do: push the expected loss below the entropy rate of the data. Everything above it is a KL divergence from the truth.

:::thm Convention | Perplexity
The perplexity of a model on a text is $e^L$ for a loss of $L$ nats per symbol: the number of equally likely choices that would be as surprising. Week 7's transformer has a validation loss of 1.576 nats per character in its reference run, which is 2.27 bits per character and a perplexity of 4.8.
:::

:::thm Proposition | Maximum likelihood minimizes a KL divergence
Let $\hat p$ be the empirical distribution of training examples $x_1, \dots, x_N$. Then
$$\frac1N\sum_{i=1}^N -\log q_\theta(x_i) = H(\hat p) + D(\hat p\,\|\,q_\theta),$$
so maximizing the likelihood over $\theta$ is minimizing $D(\hat p\,\|\,q_\theta)$, the divergence of the mass-covering kind in section 3.
:::proof Proof
The left side is the cross-entropy $H(\hat p, q_\theta)$; apply its decomposition from section 3.
:::

Week 3 comes to maximum likelihood from the side of statistics.

The proposition counts only the bits for the data. A receiver also needs the model, and an honest count adds its description: this is the *minimum description length* principle (Rissanen 1978), an information-theoretic form of the trade-off between fit and complexity. Week 7's transformer would compress the 111,540 held-out characters to about 31.7 kB, against 111.5 kB uncompressed (third check question); its 0.8 million parameters take about 3.2 MB at 32 bits each.

:::thm Empirical | Language models as general compressors (Delétang et al. 2024)
Large language models used with arithmetic coding compress text far better than general-purpose compressors, and, though trained mostly on text, they also compress image patches and audio better than PNG and FLAC. This holds when the size of the model is not counted. When it is added to the compressed size, the large models lose on datasets of the sizes studied.
:::

:::thm Empirical | The entropy of English (Shannon 1951)
Shannon had people guess printed English one letter at a time (26 letters and the space) and turned their guessing statistics into bounds on the entropy rate: with long contexts, roughly between 0.6 and 1.3 bits per letter.
:::

## 7. Estimating entropy from a sample

The second experiment estimates $H(\text{next character}\mid\text{previous }k)$ for Shakespeare. The obvious estimator plugs in frequencies: count, and compute the entropy of the counts.

:::thm Proposition | The plug-in estimate is biased downwards
Let $\hat p$ be the empirical distribution of $n$ i.i.d. draws from $p$. Then $\mathbb{E}\,H(\hat p) \le H(p)$, with strict inequality unless $p$ is a point mass.
:::proof Proof
$H$ is concave on the simplex, since each $-t\log t$ is, and $\mathbb{E}\,\hat p = p$. Jensen's inequality gives $\mathbb{E}\,H(\hat p) \le H(\mathbb{E}\,\hat p) = H(p)$. If $p$ is not a point mass, $\hat p \ne p$ with positive probability (all draws can be equal), and $H$ is strictly concave, so the inequality is strict.
:::

:::thm Theorem | Size of the bias (Miller 1955)
If $p$ gives positive probability to exactly $m$ outcomes, then as $n \to \infty$
$$\mathbb{E}\,H(\hat p) = H(p) - \frac{m - 1}{2n\ln 2} + o(1/n) \quad\text{bits}.$$
:::proof Proof sketch
In nats, expand $H$ to second order around $p$: $H(\hat p) \approx H(p) + \sum_i (-\ln p_i - 1)(\hat p_i - p_i) - \sum_i \frac{(\hat p_i - p_i)^2}{2p_i}$. The linear term has mean 0, and $\mathbb{E}(\hat p_i - p_i)^2 = p_i(1 - p_i)/n$, so the quadratic term has mean $-\frac1{2n}\sum_i (1 - p_i) = -\frac{m-1}{2n}$. Controlling the remainder takes care, since $-t\ln t$ is not smooth at 0 (Paninski 2003).
:::

The bias grows with the number of outcomes and shrinks with the sample size. For the conditional entropy with $k$ characters of context, the outcomes are (context, character) pairs; their number grows roughly exponentially in $k$ while the text stays at about a million characters. A context seen only once contributes exactly 0 to the plug-in estimate, since its one follower looks certain, so beyond some $k$ the estimate measures the sample size rather than the text.

The honest alternative is the one used for every model in this course: build the model on training data and measure its cross-entropy on held-out data. By part 3 of the proposition in section 6, its expectation is at least the entropy rate, whatever the model. A held-out loss estimates an upper bound, and a better model gives a lower one; an in-sample loss bounds nothing. The gap between the two is the gap between training and validation loss that week 4 noted for the transformer of week 7.

Counts of long contexts are mostly zero, so a held-out model must give some probability to pairs it never saw. The second experiment uses a classical scheme from text compression.

:::thm Definition | Witten–Bell interpolation (Witten and Bell 1991)
Let $n(c, a)$ count how often character $a$ followed context $c$ in the training text, $n(c) = \sum_a n(c, a)$, and $u(c)$ the number of distinct characters seen after $c$. With $c'$ the context $c$ shortened by its oldest character,
$$P(a\mid c) = \frac{n(c, a) + u(c)\, P(a\mid c')}{n(c) + u(c)},$$
starting from the uniform distribution over the alphabet; a context never seen keeps $P(a\mid c')$. The weight $u(c)$ estimates how often "something new" follows $c$ by how often it did.
:::

:::check
A source emits A with probability 0.99 and B with probability 0.01. What is its entropy? What is the smallest expected length of a code that codes one letter at a time, and how does arithmetic coding do on $n$ letters?
---
$h(0.01) = 0.01\log 100 + 0.99\log\frac{1}{0.99} \approx 0.0664 + 0.0144 = 0.0808$ bits. Every letter-by-letter code needs at least one bit per letter, and $A \mapsto 0$, $B \mapsto 1$ achieves 1. Arithmetic coding with the true model spends less than $\sum_t -\log q(x_t) + 2$ bits, which is $0.0808\,n + 2$ on average (section 5). The first experiment measures it.
:::

:::check
Let $X$ and $Y$ be independent fair bits and $Z = X \oplus Y$, their sum mod 2. Compute $I(X;Y)$ and $I(X;Y\mid Z)$. What does this say about a three-circle version of the diagram in section 2?
---
$I(X;Y) = 0$ by independence. $X$ is independent of $Z$, so $H(X\mid Z) = 1$; but given $Z$, $Y$ determines $X$, so $H(X\mid Y, Z) = 0$. Hence $I(X;Y\mid Z) = 1$: conditioning can create dependence. The central region of a three-circle diagram would have to be $I(X;Y) - I(X;Y\mid Z) = -1$, a negative area, so for three variables the diagram cannot be read as areas.
:::

:::check
Week 7's transformer reaches a validation loss of 1.576 nats per character on the 111,540 held-out characters of Tiny Shakespeare. How large a file would arithmetic coding with this model produce, and what else would a receiver need?
---
$1.576/\ln 2 \approx 2.274$ bits per character, so about $2.274 \times 111{,}540 \approx 253{,}600$ bits, or 31.7 kB, against 111.5 kB at 8 bits per character (section 6). The receiver also needs the model: 0.8 million parameters, about 3.2 MB at 32 bits each, a hundred times the compressed text. Counting both parts is the minimum description length principle; for a long enough text the cost of the model is spread thin.
