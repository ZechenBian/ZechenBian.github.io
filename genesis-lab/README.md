# 创世实验室 · Genesis Lab

输入创世参数，页面真的在浏览器里积分爱因斯坦方程，看会生出什么样的宇宙；再反过来，只凭观测数据猜出一个隐藏宇宙的样子。

- 网址：`https://zechenbian.github.io/genesis-lab/`（合并后）
- 新展区的约定：引擎一个文件（`src/<name>.js`，Node 里能 require、能测），页面模块和 HTML 片段放 `src/halls/<name>.js`、`src/halls/<name>.html`，`build.js` 里登记；页面模块通过 `window.GENESIS_HALLS` 挂进展区切换，用 `GENESIS.chart/fit/sig/...` 画图
- 源码：`src/`；构建：`node build.js` → `index.html`（单文件，GitHub Pages 不跑构建）
- 测试：`npm test`（`cosmo`、`godel`、`q`、`nbody` 四组：引擎和解析解逐个对照，N 体的小幅度增长和线性理论的 D(a) 对照）；仓库根目录的冒烟测试

## 两个版本（同一份源码）

| 版本 | 网址 | 多了什么 |

## 数据标签

- **真实**：只有"我们的宇宙"这组参数（Planck 2018，TT,TE,EE+lowE+lensing）；Ω_r 由 T_CMB = 2.7255 K 和三代中微子算出。
- **模拟**：其余一切——内置的理想化宇宙、反推台的观测、哥德尔宇宙的星空。标签直接放在数据旁边。

## 样本为什么这样做（铺开时照着做）

1. **先现象后公式**：每个展区先让玩家拨、量、发光，解释折叠在"读完你自己的发现之后再看"里。新展区（各向异性宇宙、N 体结构形成、CMB 声学峰）照此。
2. **底层永远是方程的数值解**，不用查表、不用插图：新物理先写引擎 + 解析解测试（`test/`），再写页面。有闭式解的极限（EdS、de Sitter、Milne、封闭物质宇宙、辐射宇宙、哥德尔折返半径）都要对上。
3. **死寂的宇宙要能解释自己为什么死**：诊断给出的是"死在哪一步"（没有热的开端 / 扰动长不成星系 / 恒星没时间），带具体数字，而不是一个分数。
4. **反推关卡的数据要让结论可被检验**：给玩家一个"假设检验"按钮（如 Ω_Λ = 0 的最佳拟合），让"必须有暗能量"是玩家自己否证出来的，不是被告知的。
5. **每个数据集标"真实 / 模拟"**，真实的写来源；模拟的噪声量级向真实观测看齐。

## 量子版的近似（页面上也标了）

- 核合成：弱作用速率是玻恩近似的相空间积分（无辐射修正），氘瓶颈阈值按标准参数校准到 Y_p = 0.247 这一个数；D/H 是经验标度律。
- 复合：Saha 平衡，比 Peebles 三能级计算早约 4%（z_dec ≈ 1131 vs 1090）；声学视界随之略小（141 vs 144 Mpc）。
- 热历史：瞬时中微子退耦（2 MeV）、QCD 相变取 150 MeV 的台阶、暴胀取慢滚 + 瞬时再加热（T_reh = 0.3 V^{1/4}）。
- 圈量子宇宙学：平坦情形的有效方程，曲率项按经典处理。
