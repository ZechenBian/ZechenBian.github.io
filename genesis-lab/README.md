# 创世实验室 · Genesis Lab

输入创世参数，页面真的在浏览器里积分爱因斯坦方程，看会生出什么样的宇宙；再反过来，只凭观测数据猜出一个隐藏宇宙的样子。

- 网址：`https://zechenbian.github.io/genesis-lab/`（合并后）
- 源码：`src/`；构建：`node build.js` → `index.html`（单文件，GitHub Pages 不跑构建）
- 测试：`node test/cosmo.test.js`、`node test/godel.test.js`（引擎和解析解逐个对照）；仓库根目录的冒烟测试

## 两个版本（同一份源码）

| 版本 | 网址 | 多了什么 |
|---|---|---|
| 经典版 | `genesis-lab/` | 三个展区：创世台、哥德尔旋转宇宙、反推台。底层只有广义相对论；量子物理只以固定的数进来（Ω_r 由 T₀ 的黑体公式算出、复合温度 2970 K、原初扰动幅度） |
| 量子版 | `genesis-lab/quantum/` | 创世台多一组"量子旋钮"（T₀、N_eff、Ω_b、A_s、n_s、r、α、m_e、Q、G_F、圈量子宇宙学反弹）和一组由量子物理算出的卡片（氦丰度、D/H、复合红移、声学视界、暴胀能标、德西特温度）；多一个展区"最初三分钟"：按对数时间慢放从普朗克时间到复合的热历史 |

`node build.js` 一次构建两个版本；量子版的引擎在 `src/q/`（`thermal.js` 粒子汤与 g*(T)、`bbn.js` 半解析核合成、`recomb.js` Saha 复合与声学视界、`inflation.js` 暴胀能标），页面逻辑 `src/q/app_q.js` 通过 `app.js` 的钩子接进创世台。

## 三个展区（两版共有）

| 展区 | 玩家做什么 | 底层 |
|---|---|---|
| 创世台 | 拨 H₀、Ω_m、Ω_r、Ω_Λ、w，或掷骰子，或选十一组内置宇宙；看影片、a(t)、线性扰动 δ(a)、命运卡和宜居诊断 | `cosmo.js`：从今天出发用 RK4 向过去和未来积分加速度方程（在回转/反弹处不出问题），年龄与 ∫da/(aE) 互相核对；线性增长以 ln a 为自变量积 Mészáros 方程；粒子/事件视界、距离、纪元都算出来 |
| 哥德尔旋转宇宙 | 量星空自转周期反推 ω；从轴上闪光看光绕回来；拖动看光锥随半径倾倒、越过 sinh r = 1 后绕轴一圈成为闭合类时曲线 | `godel.js`：Hawking–Ellis 柱坐标形式的哥德尔度规，在轴上不奇异的笛卡尔型坐标里数值积分零测地线（克氏符从度规按定义算），E、L 守恒量核对 |
| 反推台 | 第一关"命运之谜"：隐藏宇宙的模拟观测（60 颗已定标超新星、8 把 147 Mpc 标准尺、最老恒星年龄）；调 H₀、Ω_m、Ω_Λ 拟合，可检验"Ω_Λ = 0 解释得了吗"，锁定后比几何、命运、参数 | `puzzles.js`：六个隐藏宇宙，噪声量级按真实巡天；χ² 实时计算 |

## 数据标签

- **真实**：只有"我们的宇宙"这组参数（Planck 2018，TT,TE,EE+lowE+lensing）；Ω_r 由 T_CMB = 2.7255 K 和三代中微子算出。
- **模拟**：其余一切——内置的理想化宇宙、反推台的观测、哥德尔宇宙的星空。标签直接放在数据旁边。

## 样本为什么这样做（铺开时照着做）

1. **先现象后公式**：每个展区先让玩家拨、量、发光，解释折叠在"读完你自己的发现之后再看"里。新展区（各向异性宇宙、N 体结构形成、CMB 声学峰）照此。
2. **底层永远是方程的数值解**，不用查表、不用插图：新物理先写引擎 + 解析解测试（`test/`），再写页面。有闭式解的极限（EdS、de Sitter、Milne、封闭物质宇宙、辐射宇宙、哥德尔折返半径）都要对上。
3. **死寂的宇宙要能解释自己为什么死**：诊断给出的是"死在哪一步"（没有热的开端 / 扰动长不成星系 / 恒星没时间），带具体数字，而不是一个分数。
4. **反推关卡的数据要让结论可被检验**：给玩家一个"假设检验"按钮（如 Ω_Λ = 0 的最佳拟合），让"必须有暗能量"是玩家自己否证出来的，不是被告知的。
5. **每个数据集标"真实 / 模拟"**，真实的写来源；模拟的噪声量级向真实观测看齐。

## 量子版的近似（页面上也标了）

- 核合成：弱作用速率是玻恩近似的相空间积分（无辐射修正），氘瓶颈阈值按标准参数校准到 Y_p = 0.247 这一个数；D/H 是经验标度律。
- 复合：Saha 平衡，比 Peebles 三能级计算早约 4%（z_dec ≈ 1131 vs 1090）；声学视界随之略小（141 vs 144 Mpc）。
- 热历史：瞬时中微子退耦（2 MeV）、QCD 相变取 150 MeV 的台阶、暴胀取慢滚 + 瞬时再加热（T_reh = 0.3 V^{1/4}）。
- 圈量子宇宙学：平坦情形的有效方程，曲率项按经典处理。
